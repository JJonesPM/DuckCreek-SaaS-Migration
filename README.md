# Duck Creek SaaS Migration for Insurance Billing

## Overview
As Senior Product Owner at Allstate (2021–2024), I led the migration of a legacy insurance quoting and billing system to the Duck Creek SaaS platform, streamlining operations for 500K+ users. This project reduced processing time by 25%, enabled $10M in new premium revenue, and achieved 100% regulatory compliance. Leveraging Agile (SAFe) methodologies, AWS cloud infrastructure, and RESTful APIs, I aligned 20+ cross-functional team members and 50+ stakeholders to deliver under tight deadlines.

## Key Achievements
- **Efficiency**: Cut billing processing time by 25% via Duck Creek’s SaaS capabilities.
- **Revenue Impact**: Enabled $10M in new premium revenue through streamlined quoting.
- **Scalability**: Supported 500K+ users with AWS-integrated APIs handling high transaction volumes.
- **Compliance**: Navigated regulatory ambiguity, achieving 100% compliance across states.

## My Role
- Defined product roadmap using SAFe, prioritizing user stories for quoting and billing workflows.
- Collaborated with engineering to integrate Duck Creek with AWS (API Gateway, Lambda).
- Conducted user acceptance testing (UAT) and A/B testing to optimize user experience.
- Managed vendor relationships with Duck Creek, ensuring alignment with Allstate’s goals.

## Tech Stack
- **Platform**: Duck Creek SaaS (Policy, Billing modules)
- **Cloud**: AWS (API Gateway, Lambda, S3)
- **Tools**: JIRA, Confluence, GitHub (workflow management), SQL
- **APIs**: RESTful APIs for real-time quoting and billing
- **Methodologies**: SAFe, Scrum
